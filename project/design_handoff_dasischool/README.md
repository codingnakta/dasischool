# Handoff: 다시학교 랜딩 + 입학 신청 폼 (모바일)

## Overview
성인 친목학교 "다시학교" 0기 학생 모집용 모바일 랜딩 페이지와 10단계 입학 신청 폼. 목표는 신청 전환. 랜딩의 모든 "입학 신청" 버튼은 신청 폼으로 이동한다.

## About the Design Files
이 폴더의 `.dc.html` 파일들은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 이다. 의도한 모양과 동작을 보여주는 용도이며, 그대로 배포하는 프로덕션 코드가 아니다. 과제는 이 디자인을 대상 코드베이스의 환경(Next.js/React 등, 없다면 적절한 프레임워크 선택)에서 그 환경의 패턴과 라이브러리로 **재구현**하는 것이다.

파일 구조: `<x-dc>` 안의 마크업이 템플릿(인라인 스타일), `<script data-dc-script>` 안의 `class Component`가 상태/로직. `{{ 이름 }}`은 로직 클래스의 `renderVals()`가 돌려주는 값이 들어가는 자리. `<sc-if>`는 조건부 렌더, `<sc-for>`는 반복. `<image-slot>`은 사진 자리 플레이스홀더로, 실제 구현에서는 `<img>` / `next/image`로 대체.

## Fidelity
**High-fidelity.** 색, 타이포, 간격, 카피, 인터랙션 모두 최종안. 픽셀 단위로 재현할 것. 카피는 아래 그대로 사용 (수정 금지).
